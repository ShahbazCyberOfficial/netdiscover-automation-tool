# Netdiscover Automation Tool

A simple and user-friendly Python automation tool for Netdiscover that helps discover live hosts on a local network with minimal user input.

Developed by: **Shahbaz Bhutta**

---

# Features

- Live Host Discovery
- Network Range Scanning
- MAC Address Detection
- Vendor Identification
- Beginner-Friendly Interface
- Keyboard Interrupt (Ctrl + C) Handling
- Simple Command-Line Interface
- Fast Network Discovery

---

# Requirements

- Python 3.x
- Netdiscover
- Linux (Recommended: Kali Linux)

# Usage

Run the tool:

```bash
python3 netdiscover_automation.py
```

Example Input

Network Interface

```
eth0
```

or

```
wlan0
```

Network Range

```
192.168.1.0/24
```

or

```
10.0.0.0/24
```
