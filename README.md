# Netdiscover Automation Tool

A lightweight Python automation tool that simplifies network host discovery using Netdiscover.

## Features

- Live Host Discovery
- Network Range Scanning
- MAC Address Detection
- Vendor Identification
- Beginner-Friendly Interface
- Keyboard Interrupt Handling (Ctrl + C)
- Clean Terminal Output

## Requirements

- Python 3.x
- Netdiscover
- Linux (Kali Linux Recommended)

## Installation

```bash
sudo git clone https://github.com/ShahbazCyberOfficial/netdiscover-automation-tool.git

cd netdiscover-automation-tool

sudo chmod +x netdiscover_automation.py

sudo python3 netdiscover_automation.py
